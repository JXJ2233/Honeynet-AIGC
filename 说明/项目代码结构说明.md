# Honeynet-AIGC 项目代码结构说明

## 项目概述

基于斯坦纳树优化的混合专家模型蜜罐主动诱导防御系统。系统通过 SCB 因子筛选、OSE 优化排序、斯坦纳树构建和遗传算法优化四个核心算法模块，实现蜜罐节点的最优部署。

## 核心算法流程

```
输入网络拓扑
    │
    ▼
[SCB因子筛选] ── 基于安全、成本、平衡因子筛选候选节点
    │
    ▼
[OSE优化排序] ── 多维重要性评分 + TOPSIS综合排序
    │
    ▼
[斯坦纳树构建] ── 构建连接终端节点的最小成本树
    │
    ▼
[遗传算法优化] ── 种群进化寻找最优蜜罐部署方案
    │
    ▼
输出最优部署方案
```

## 模块功能说明

| 模块 | 功能 |
|------|------|
| **SCB筛选器** | 对候选节点进行安全、成本、平衡三维度评分过滤 |
| **OSE优化器** | 基于节点度数中心性、介数中心性等指标综合排序 |
| **斯坦纳树** | 构建连接终端节点的最小成本树，支持动态扰动与租户隔离 |
| **遗传算法** | 种群初始化、适应度评估、选择交叉变异、精英保留 |
| **攻击模拟器** | 模拟多种攻击类型（扫描、横向移动、提权、DDoS等） |
| **帕累托分析** | 多目标优化中的帕累托前沿分析和可视化 |
| **评估器** | 综合评估解决方案的经济性、安全性等指标 |

## 服务架构

- **B组后端** (backend_service.py) - FastAPI 服务，提供核心算法API
- **D组网关** (services/d_gateway_service.py) - 安全网关中间件，攻击检测与请求转发
- **D组蜜罐** (services/d_honeypot_service.py) - 蜜罐虚假推理服务
- **前端页面** - Streamlit 构建的3D沙盘推演台和指挥中心仪表盘
