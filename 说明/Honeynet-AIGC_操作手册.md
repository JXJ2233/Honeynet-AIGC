## 二、环境准备与启动

### 2.1 环境要求

- **操作系统**: Windows 10/11
- **Python**: 3.9+
- **依赖**: 见 `requirements.txt`

### 2.2 一键启动（推荐）

项目提供了两种启动方式：

**方式一：分页启动（推荐用于测试）**
双击 `一键启动（分页启动）.bat`，将依次：
1. 清理旧进程（端口 8000/5000/8501/8502）
2. 检查 Python 环境
3. 自动创建虚拟环境 `venv`
4. 安装依赖
5. 启动后端服务（端口 8000）
6. 启动蜜罐攻击仿真（端口 5000）
7. 启动算法工作台（端口 8501）
8. 启动态势指挥中心（端口 8502）
9. 自动打开浏览器访问蜜罐攻击仿真页面

**方式二：整体启动（推荐用于完整测试）**
双击 `一键启动（整体）.bat`，将额外启动：
- 统一登录门户（端口 8503）
- 自动打开浏览器访问登录门户

### 2.3 手动启动

如需手动启动各服务，请按以下顺序：

```bash
# 1. 激活虚拟环境
venv\Scripts\activate

# 2. 启动后端API服务（端口 8000）
python backend_service.py

# 3. 启动安全网关服务（端口 8001）
python services/d_gateway_service.py

# 4. 启动蜜罐虚假推理服务（端口 8002）
python services/d_honeypot_service.py

# 5. 启动蜜罐攻击仿真（端口 5000）
python _pages/02_Honeypot_Attack.py

# 6. 启动算法工作台（端口 8501）
streamlit run _pages/01_Algorithm_Workbench.py --server.port 8501

# 7. 启动态势指挥中心（端口 8502）
streamlit run _pages/03_Command_Center.py --server.port 8502

# 8. 启动统一登录门户（端口 8503）
streamlit run home.py --server.port 8503
```

### 2.3 注意事项

- 启动脚本会自动清理旧进程，如果手动启动请确保端口未被占用
- 首次启动会自动创建虚拟环境并安装依赖，可能需要几分钟
- 所有服务启动后，终端窗口可以最小化，不要关闭

## 四、算法工作台（3D全息攻防沙盘）

### 4.1 访问地址

http://localhost:8501  
或从登录门户 → 拓扑策略引擎

### 4.2 功能概述

MoE-SHD 3D全息攻防沙盘推演台，提供交互式3D拓扑可视化与数学模型指标面板。核心功能是展示蜜罐部署优化的三阶段算法流水线。

### 4.3 操作步骤

#### 步骤1：选择场景

在右侧 **Environment Profile** 面板中，选择推演场景：

| 场景 | 特点 | 安全权重 | 延迟权重 | 成本权重 |
|------|------|---------|---------|---------|
| 通用数据中心 | 均衡配置 | 0.35 | 0.30 | 0.35 |
| 金融结算中心 | 极高安全敏感 | 0.65 | 0.20 | 0.15 |
| 政务数据专网 | 合规与隐私导向 | 0.75 | 0.10 | 0.15 |
| 工业控制系统 | 毫秒级控制 | 0.35 | 0.55 | 0.10 |
| 医疗物联网 | 延迟+安全双敏感 | 0.40 | 0.40 | 0.20 |
| 教育科研云 | 成本驱动 | 0.30 | 0.25 | 0.45 |
| 边缘算力网络 | 资源受限 | 0.20 | 0.20 | 0.60 |

#### 步骤2：推进算法流水线

在左侧 **Algorithm Pipeline** 面板中，依次点击三个按钮：

1. **Base**（阶段0）：显示全量网络拓扑
   - 展示所有节点（Internet/Core/SCB/Aggregation/Edge/Server/Honeypot）
   - 节点按Fibonacci球体均匀分布在多层同心球壳上

2. **SCB Filter**（阶段1）：SCB因子筛选
   - 基于安全(Security)、成本(Cost)、平衡(Balance)三因子筛选
   - 保留约52%的高潜力节点
   - 3D视图中灰色节点为被筛除节点

3. **Steiner**（阶段2）：斯坦纳防御拓扑
   - 构建最小斯坦纳树连接终端节点
   - 显示蜜罐最优部署位置
   - 数学模型面板显示综合成本指标

#### 步骤3：查看数学模型指标

在Steiner阶段，左侧面板显示：
- **综合成本公式**: F(Sol) = wA·ĈR + wB·ĈL + wC·Ŝloss
- **归一化指标**: 资源成本(ĈR)、延迟成本(ĈL)、安全损失(Ŝloss)
- **约束检查**: 预算约束、延迟约束、安全覆盖度约束的实时状态

#### 步骤4：执行攻击模拟

1. 确保已推进到 Steiner 阶段
2. 在 **Threat Simulation** 区域的文本框中输入攻击载荷
3. 点击 **Execute Attack** 按钮
4. 3D视图中会显示攻击路径动画（红色粒子线）
5. 左侧 **Incident Log** 记录攻击拦截日志

### 4.4 3D视图操作

- **旋转**: 鼠标左键拖拽
- **缩放**: 鼠标滚轮
- **平移**: 鼠标右键拖拽
- **节点拾取**: 鼠标悬停节点可查看信息

### 4.5 右侧面板解读

- **AHP Weights**: 显示当前场景的安全/延迟/成本权重分配
- **Constraints**: 显示CPU/MEM/BW的资源使用率与阈值
- **Algorithmic Edge**: 显示MoE-SHD相比Random-K的优化增益百分比

## 五、蜜罐攻击仿真（对抗仿真平台）

### 5.1 访问地址

http://localhost:5000  
或从登录门户 → 对抗仿真平台

### 5.2 功能概述

综合攻击检测与蜜罐诱导仿真沙箱，覆盖SQL注入、XSS、命令注入、提示词注入等7大类攻击。提供攻击检测、流量动画、攻击面分布图、诱导拦截流水线、隔离沙箱日志等完整攻击链模拟。

### 5.3 操作步骤

#### 步骤1：选择攻击载荷类别

在左侧面板的 **ATTACK VECTOR** 下拉菜单中，选择攻击类型：

| 攻击类型 | 说明 |
|---------|------|
| SQL注入 | 数据库注入攻击检测 |
| XSS | 跨站脚本攻击检测 |
| 命令注入 | 系统命令注入攻击检测 |
| 暴力破解 | 密码暴力破解检测 |
| 文件上传 | 恶意文件上传检测 |
| CSRF/SSRF | 跨站请求伪造检测 |
| 提示词注入 | 大模型提示词注入检测 |
| 对抗性混淆 | 编码混淆攻击检测 |

#### 步骤2：输入攻击载荷

在 **PAYLOAD INPUT** 文本框中输入攻击载荷文本。也可以点击 **LOAD PRESET** 按钮加载预设攻击语句。

#### 步骤3：语义分析

点击 **ANALYZE** 按钮进行攻击检测：
- 系统使用100+正则规则进行匹配
- 显示匹配结果：是否检测到攻击、攻击类型、置信度、匹配的关键词
- 置信度计算公式：`min(0.3 + 匹配数×0.15 + 关键词数×0.05, 0.95)`

#### 步骤4：执行注入

点击 **EXECUTE INJECTION** 按钮触发完整攻击链模拟：
- **流量动画**: 顶部显示攻击流量粒子动画
- **攻击面分布**: 右侧Chart.js柱状图显示各类攻击的分布
- **诱导拦截流水线**: 显示攻击被蜜罐诱导拦截的过程
- **隔离沙箱日志**: 底部终端风格日志逐行输出

### 5.4 界面布局

- **左侧面板**（340px）：攻击载荷选择、输入、分析、执行
- **右侧面板**：
  - 顶部：两个图表（攻击面分布 + 拦截流水线）
  - 中部：诱导拦截流水线详情
  - 底部：隔离沙箱日志

### 5.5 预设攻击语句

系统内置16条预设攻击语句，涵盖各类攻击场景，方便快速演示。

## 八、常见问题与故障排除

### 8.1 启动失败

**问题**: 双击bat文件后窗口闪退  
**解决**: 
1. 右键bat文件 → "以管理员身份运行"
2. 检查Python是否安装：`python --version`
3. 检查端口是否被占用：`netstat -ano | findstr ":8000"`

### 8.2 端口被占用

**问题**: 启动时提示端口被占用  
**解决**: 
1. 启动脚本会自动清理旧进程
2. 手动清理：`taskkill /F /PID <进程ID>`
3. 或重启电脑

### 8.3 页面无法访问

**问题**: 浏览器打开页面显示"无法访问此网站"  
**解决**:
1. 确认服务已启动（终端窗口未关闭）
2. 检查端口号是否正确
3. 等待几秒后刷新页面（服务启动需要时间）

### 8.4 3D视图不显示

**问题**: 算法工作台的3D视图空白  
**解决**:
1. 确保浏览器支持WebGL（Chrome/Firefox/Edge均可）
2. 检查后端服务是否运行（端口8000）
3. 刷新页面重试

### 8.5 蜜罐攻击仿真无响应

**问题**: 点击"执行注入"后无反应  
**解决**:
1. 确保后端服务已启动（端口8000）
2. 检查安全网关服务是否运行（端口8001）
3. 检查蜜罐服务是否运行（端口8002）

### 8.6 态势指挥中心数据不更新

**问题**: KPI数据长时间不变  
**解决**:
1. 页面每4秒自动刷新一次
2. 点击 **FORCE REFRESH** 按钮手动刷新
3. 检查后端服务是否运行

### 8.7 依赖安装失败

**问题**: pip安装依赖时报错  
**解决**:
```bash
# 升级pip
python -m pip install --upgrade pip

# 单独安装依赖
pip install fastapi uvicorn pydantic networkx pyyaml streamlit requests flask
```

### 8.8 虚拟环境问题

**问题**: 找不到venv目录  
**解决**: 启动脚本会自动创建虚拟环境，也可以手动创建：
```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```
